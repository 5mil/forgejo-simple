# Repository Structure

This file explains what each folder is for.

## docs/
Planning and status documents.
- `SIMPLIFICATION.md` – high-level goals
- `ROADMAP.md` – phases
- `NEXT.md` – what the next action is
- `STRUCTURE.md` – this file

## patches/
Descriptions of code changes we intend to make to upstream Forgejo.
These are currently documentation; real unified diffs will be added later.

## examples/
Sample configuration files that the simplified installer should produce.

## scripts/
Helper scripts for future use once we have a full source tree and build environment.
